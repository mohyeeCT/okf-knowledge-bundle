# Website OKF Knowledge Bundle

**A reusable skill for Claude, Codex and compatible ChatGPT workspace agents.** Turn supported website facts into a reviewed, unpublished `okf/` folder that a developer can host on the client's website after approval.

## Downloads

- [Claude skill ZIP](claude/okf-knowledge-bundle.zip)
- [OpenAI/Codex skill ZIP](openai/okf-knowledge-bundle-openai.zip)
- [Codex skill folder](openai/okf-knowledge-bundle)

Example first request:

> Use okf-knowledge-bundle for example.com. Use the sitemap route, English pages, up to 20 pages. Explain the scope and any provider budget first. Keep everything unpublished, give me a short review and flag only critical conflicts.

## Scope and limits

The workflow supports B2B, B2C, local, service, ecommerce and mixed business profiles. Each job still needs bounded scope and human review. Source quotes and software validation do not independently certify business truth. Website changes may require renewed evidence and review. This is not an unattended site publisher and does not promise rankings, indexing or AI citations.

OKF is an external format; this project is not an official Google product. See the [upstream specification](https://github.com/GoogleCloudPlatform/open-knowledge-format/blob/main/SPEC.md).
